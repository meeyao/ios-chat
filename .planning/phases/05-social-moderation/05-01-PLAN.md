  <files>Sources/DankChatCore/Services/Helix/HelixAPIClient.swift, Sources/DankChatCore/Services/Helix/HelixRequest.swift, Sources/DankChatCore/Services/Helix/HelixError.swift, Sources/DankChatCore/Services/Helix/HelixScope.swift</files>
  <action>
Create a small Helix client module:
- `HelixAPIClient` builds requests to `https://api.twitch.tv/helix`, injects `Client-Id` and `Authorization: Bearer`, and decodes `Decodable` responses.
- `HelixRequest` encapsulates method/path/query/body and optional required scopes.
- `HelixError` captures HTTP status + payload for error surfacing.
- `HelixScope` defines string constants for required scopes (moderation, whispers, followage, block/unblock, chat settings).

Constraints:
- Use `URLSession` (no new dependencies).
- Expose a `tokenProvider: () async -> String?` so callers can integrate with `AuthManager`.
- Keep the API simple enough for feature-specific services to wrap.
  </action>
  <verify>
Build: `swift build`
  </verify>
  <done>
Helix client compiles, builds requests with headers, and surfaces errors via `HelixError`.
  </done>
</task>

  <action>
Implement a `HelixUsersService` that calls `GET /users` and returns the signed-in user’s `id`, `login`, and `display_name`.

Create `UserIdentityStore` (ObservableObject) with:
- `@Published var user: HelixUser?`
- `refresh()` that calls `HelixUsersService`, clears on auth sign-out, and guards against missing tokens.

Wire into `ContentView`:
- Create `HelixAPIClient` with `clientId` from `AppConfiguration` and a token provider using `AuthManager.state`.
- Instantiate `UserIdentityStore` as `StateObject` and inject via `.environmentObject`.
- Call `identityStore.refresh()` on auth sign-in and on app start if token exists.

Update `AppConfiguration` default OAuth scopes to include:
`moderator:manage:banned_users`, `moderator:manage:chat_messages`, `moderator:manage:chat_settings`,
`moderator:read:chat_settings`, `moderator:read:followers`, `user:manage:blocked_users`, `user:manage:whispers`.
