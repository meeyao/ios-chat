  <action>
Create a unified emote data model and store in `DankChatCore`:

- Define normalized `Emote` model: provider id, code, image URLs (prefer WebP when available), isAnimated, and source provider.
- Implement provider clients for:
  - Twitch (global + channel emotes; also map channel login -> broadcaster id via Helix users)
  - BTTV (global + channel)
  - FFZ (global + channel)
  - 7TV (global + channel)

Implement `EmoteStore`:
- Loads global sets at startup.
- Loads per-channel sets on channel join / activation.
- Applies collision precedence locked in context: `Twitch > 7TV > BTTV > FFZ`.
- Exposes query APIs needed by UI:
  - list emotes by provider (for menu tabs)
  - resolve by code (for suggestions)
  - (optional) resolve by twitch tag occurrence id/range

Include a periodic refresh mechanism for BTTV/FFZ (join + periodic). Keep refresh intervals reasonable and configurable.
  </action>
